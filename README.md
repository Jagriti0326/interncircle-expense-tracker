
# Python Expense Tracker

A beginner-friendly Python project that helps users record and manage daily expenses using a CSV file.

## Features

- Add expenses with date, category, description, and amount.
- View all saved expenses.
- Filter expenses by category.
- Filter expenses by month.
- View category-wise spending totals.
- Calculate total expenses.
- Identify the largest expense.
- Store records in a CSV file.

## Technologies Used

- Python
- CSV module
- datetime module
- collections module

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run:

   ```bash
   python main1.py
   ```
